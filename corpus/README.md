# 语料与阅读证据

本目录保存文件身份清单、逐文件处理状态和原创精读笔记。原始 PDF、提取全文、翻译中间正文及论文截图只留在本地来源目录或被版本控制忽略的 `.work/` 中，不进入这份知识库。非论文发票只登记排除状态，不复制敏感正文。

当前来源目录是 `D:\Pile\literature`。文件路径与散列用于定位版本，不授予原论文再分发权。

## 数量口径与入口

- [file_manifest.json](file_manifest.json)：107 个 PDF 的原始清点与 SHA-256 字节重复关系，共 82 个独立字节文件。
- [reading_manifest.json](reading_manifest.json)：可机读的原文/译文/字节副本映射、逐页覆盖、笔记散列、各文件处理状态和汇总。以该生成文件的当前统计为准。
- [source_catalog.md](source_catalog.md)：逐个 PDF 及非 PDF 辅助文件的可读目录，以及完整笔记入口。
- `papers/Pxxx.md`：原始来源对应的完整原创阅读笔记；不裁掉反例或限制。

P016–P040 和 P074 共 26 个独立字节文件是译文或翻译中间 PDF，不作为新增原始来源。映射为 P016→P015，P017–P020→P009，P021–P024→P010，P025–P028→P011，P029–P032→P012，P033–P036→P013，P037–P040→P014，P074→P046。其余字节副本按 `file_manifest.json` 的 `duplicate_of` 继续追溯。

归并后有 56 个原始来源，其中 P044 为非论文电子发票并排除；剩余 55 份论文、报告或学位来源。P063 是原文、讨论及作者答复的拼接 PDF，因此这里使用“来源文件数”，不把它强称为严格的 55 篇文章。跨领域来源保留表达或图表参考价值，不能成为岩土物理结论的依据。

## 阅读覆盖怎样解释

所有页码为从 1 开始的 PDF 页序。`read_text_pages` 记录逐页读取的文本，`read_visual_text_pages` 记录依靠页面图像补读的文字，`visual_pages` 单独记录实际视觉查看的关键图表页面，`blank_or_separator_pages` 说明空白或分隔页。图像文字页可能与其他集合重叠，不能简单相加当作不同页面。

`read_complete` 仅表示所有 PDF 页已由文本、图像文字或空白/分隔页记录解释；不表示每一张图表都已经逐图视觉审查。实际图表选择和适用边界以每篇笔记为准。公式与扫描图只按阅读任务做视觉核对，并未重推或独立验证论文中的所有公式；OCR 也不能作为数学式准确性的保证。参考文献页已按覆盖记录阅读，但没有对每一条文献做外部检索、真实性或现行规范版本核实。未提供的外部补充材料没有被计作已读。

同组数据用于参数反演时，不能将符合程度改写成独立预测能力。原文的土参数、接触系数、荷载阈值、拟合参数与规范取值只保留其出处和条件，不进入模板的通用默认值。

缺少 `.md` 或 `.json` 的来源会明确生成 `pending` 占位；有未解释页面则记为 `read_partial`。生成器不会把缺失记录改为“已精读”。

## 独立 skill 的证据卡

两个 skill 的 `references/source-atlas.md` 及 `references/papers/Pxxx.md` 均在各自目录内，不依赖返回本目录的跨级链接。生成器按原笔记二级标题分离写作与图表内容；来源、覆盖、迁移边界及限制保留在两边，不认识的标题保留到两边而非删除。每段原有图号、表号和 PDF 页码保持不变。

为支持独立复制安装，共同段落的有限重复是有意的。所有卡片都从同一份完整原创笔记生成，并记录其 SHA-256，以避免手工维护造成漂移。完整笔记始终在 `corpus/papers/` 保留。

## 辅助文件与重建

来源目录中的 `.txt` 提取文本、`.csv` 曲线数据、`.png` 图片、`.log` 过程日志、`.jsonl` 翻译中间件及辅助 `.md` 都不是新增论文。`idea.docx` 已由主代理使用 OfficeCLI 确认为研究设想；`.g3x` 是外部项目文件，没有运行或验证其模型。它们逐文件列在目录中，能够从文件名/目录映射到原文时会给出 canonical ID；否则明确标为不适用。辅助文件仅登记身份，不声称已经重新核对其全部内容。

在保有本地来源与 `.work/readings/` 的工作环境中运行：

```powershell
python tools/package_evidence.py --strict
```

脚本只从成对阅读笔记与覆盖记录生成完整笔记、两组专属证据卡、目录及阅读清单，不复制原文、提取文本或截图；对非 PDF 辅助文件只登记名称、大小和分类。它可重复运行；`--strict` 在缺笔记或存在未解释 PDF 页面时返回非零，同时仍产出明确标记的可审查结果。若来源 PDF 文件增删，应先更新并核对文件清单与 ID 映射，不直接套用旧编号。
