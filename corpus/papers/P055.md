# P055 — Ultimate lateral capacity of timber poles embedded in clay

年份：2016。文献类型：ICE Geotechnical Engineering 169(GE2)；2015 online/2016 issue。

文字阅读：PDF 1–12 页；实际渲染核对页：5, 6, 7, 10。页码均为 PDF 页序。

## 全文结构与论证链

浅埋木杆与 Broms 简化的矛盾 → 传统/一般化压力分布 → 场地土和杆件布置 → 试验传感器、阶梯加载 → 无峰值曲线的双曲线外推 → 三阶段反演（原方法、加深过渡深度、简化常压力） → 排除替代解释 → 小位移刚度 → 受限范围的结论。

## 可复用写作技法

1. PDF 1–2 页先明确 pole 与会显著弯曲的 pile 不同，再指出既有图表在当前几何范围内难读；问题来自具体适用域而非笼统否定经典理论。
2. PDF 4–6 页详述原位强度是否修正、为什么不修正，区分场地平均与逐杆局部平均；将传感器质量、阶梯加载停顿与曲线锯齿联系起来。
3. PDF 6 页直说试验终止时未达到峰值，解释渐近容量是拟合外推；这是避免将“最后一步载荷”误叫“实测极限”的好例子。
4. PDF 8–9 页逐一审查仪器标定、裂隙、干湿、钻孔扰动、成桩、长短桩等替代解释，再改压力分布；这种反证顺序比仅报告拟合优度更有说服力。
5. PDF 9–12 页同时保留“可能还有其他分布”“现有埋深范围不足以精确定 ξ”的限定，简化式限定在本文短杆范围。

## 图形风格（实际视觉）

- Fig. 7，PDF 5：强度–深度散点/回归和频数直方图并列；均值直接标注，不仅给单个平均数。
- Figs. 9/11，PDF 6：载荷–位移和载荷–时间并列解释锯齿；原始点/曲线黑色，红色双曲线及渐近容量箭头，外推含义显式写出。
- Fig. 14，PDF 10：2×2；上排容量–埋深（理论曲线与绿色试验点），下排预测–测量 1:1 图；点图方形且轴范围一致，便于看偏差；无需 3D 效果。

## 表格风格（实际视觉）

- Table 1，PDF 5：杆号×取样深度矩阵，单位 kPa 在总表头、深度 m 在二级表头；缺测短横线，个别 nr 为原稿标记；表中小数使用中点为出版风格，迁移中文时统一常规小数点。
- Table 2，PDF 7：杆号、埋深、加载高度、外推容量、不同预测、日期；表下注 a/b 区分全场/局部强度，c 标明打入；Not tested 保留，不删除未测杆以误报样本量。横线清楚，无竖线、两层表头；正文表题在表下为该刊风格。

## 迁移和限制

可迁移：条件化批评经典模型、原始曲线+时间历程、测量/拟合/预测身份区分、替代解释清单、局部/总体参数对照。不可迁移：3su、过渡深度、打入修正系数或土模量为通用默认。本地文件名 pender2015 不等于正式卷期年。
