# P012 — Improving Tilted Foundations Over Soft Clay Using Micropiles: Numerical Analysis

年份：2023。页码均为PDF物理页。

## 结构与论证
既有倾斜建筑问题 → 现场案例 → 数值原型/施工过程 → A土性差异与B层厚差异两种解释 → 每种场景按沉降、桩头荷载、侧摩阻占比、侧摩阻分布四层推进 → 有限情境下的建议。
## 写作技法
1. pp3–7区别现场观察与假设场景：只有一个钻孔，故A/B是可解释倾斜的两个数值情景，而非已证实原因。
2. pp7–8用A/B、I/II、1–4编码正交化“原因—长度—布置/卸载”，表2说明六施工阶段；叙述能回指过程。
3. pp8–20同一解释框架重复用于两个情景，形成可直接对照的段落；先整体沉降再单桩分配，最后深度传力，避免只报告排名。
4. p21结论首条限制为该土层或类似土层，值得保留而非删除限定词。

## 迁移与限制
可学情景分支及整体→构件→传力链，不照搬错误。Eq.3按给定正沉降不能自然得到正文>100%的“控制率”；pp13、15、19–20对10/20m桩与深度区间有矛盾。定义、符号、坐标、图注需要相互核验。阶段是离散事件，新图默认折线，不将光滑曲线当连续时间响应。
