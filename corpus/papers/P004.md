# P004: Rock Socket Transmission Line Foundation Performance

年份：1994。文献类型：期刊现场试验与暂行设计建议论文。页码均为 PDF 页码（从1计）。
全文文字检查：1–7页；实际渲染视觉检查：2, 3, 4, 6, 7页。

## 全文结构与论证链

工程成本与岩基设计不确定性（1页）→十四项原型试验及场地差异（1–2页）→勘察、施工、传感器与加载制度（2–3页）→逐项响应曲线（4–6页）→暂行设计流程及逐案例回算（6–7页）。结论强调数据库价值和仍需扩展验证。

## 可复用写作技法

1. 研究动机落在“现有土基方法用于岩嵌固的保守程度不明”，并把目标限定为初始数据库及暂行建议（1页）；适合资料规模有限的工程研究。
2. 将试验结束与岩土破坏分开：3页Table II明列是否发生岩土破坏，脚注区分加载装置上限、疑似结构破坏及大位移。应将这种终止原因分类写入数据处理段。
3. 多场地材料不靠一句代表性描述：2页Table I把地质、RQD、嵌固、回填和偏心距统一到同一试验编号。
4. 设计建议紧接适用限制：6页称provisional，并明确不处理位移/转角性能；7页回算比较让建议可审查。

## 曲线与配图风格

4页Figs. 3–8为2列×3行，单图保留加载及卸载轨迹，黑色细线、四边刻度框、单位随轴名、没有装饰性色彩；现场地点和DS/DE类型放在每个图题。注释箭头直接标记不能稳定荷载、装置极限等终点，避免把末点误读为承载力。6页Fig. 17把几何示意与菱形条件决策结合，属于方法流程图而非函数图。

## 表格风格

Table I（2页）横跨双栏，主要靠对齐和空白而非完整网格分隔；列名包含ft和百分号，定义放编号脚注，保留N/A及范围值。Table II（3页）短表将“响应形态”“破坏是否发生”“最大施加弯矩”分列，是有用的状态表模板。Table III（7页）并列实际几何、无量纲比值与建议深度，通常一位小数；原始英制单位须明确转换而不能静默改标签。

## 迁移边界

- 1994年的暂行规则不是现行规范，不能作为通用设计参数。
- 扫描字体偏小、图表密集且OCR错字多，可迁移状态编码和证据结构，不应复刻其字体密度。
- 用终止原因注释表达信息，不可把所有曲线终点统一叫极限承载力。
