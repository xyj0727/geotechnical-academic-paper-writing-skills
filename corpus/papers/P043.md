## 全文结构与论证链

版本封面 → 摘要/引言 → 增强 MCC 组成、公式与统一标定 → 数值域/边界/界面/初始场 → 刚柔桩变形和间隙/应变场 → 桩身位移和弯矩对比 → 全程/小位移响应 → 两种精度度量 → 结论 → 符号/不变量与单元试验附录 → 参数表和全部图。关键身份：数值分析在现场桩测试之前完成，为 Class A 预测；不是用桩头曲线反演后再验证。

## 可复用写作技法

1. PDF 4–5 页清楚分开预测时序、模型目的与当前不覆盖的循环/速率/强度各向异性；模型功能的取舍由问题和可用试验共同决定。
2. PDF 8–12 页将强度、刚度、OCR、K0 和孔压一起校准，使它们在同一初始有效应力框架下相容；解释为什么不能只分别拟合 G0 与归一化退化曲线。
3. PDF 13–14 页从间隙深度、Lode 角、局部应变说明模型选项为什么重要，再对桩身位移/弯矩验证，形成输入假设→场量机制→整体响应的链。
4. PDF 14 页明确比较对齐条件：位移剖面按同桩头位移取值，弯矩剖面按同桩头弯矩取值，因此并非同一荷载阶段；预测无速率效应，应对比持荷段终点。
5. PDF 15 页用全程与小位移两个面积误差指标分别评估容量和服务刚度，图示误差定义，避免仅用峰值误差掩盖初始段不符。
