# P073 — 随车起重机起重臂伸缩原理及受力分析

年份：2026。类型：跨领域方法或设计论文，仅辅助写作/图表。页码均为PDF物理页。

## 结构与论证
设计阶段的计算缺口 → 单滑轮运动学 → 五节臂实例 → 各节臂自由体 → 力和弯矩递推 → 危险截面 → 伸绳/缩绳分工况递推。
## 写作技法
1. pp1–2把已有总体计算与尚需解释的局部受力分开，以“危险截面判定/绳力估算”界定本文任务。
2. p2先推导最小单元的速度约束，再扩展到五节臂，避免直接给复杂系统公式。
3. pp3–4定义通用第i节臂并分首节、中间、末节，用反力递推连接自由体；不等式结论进一步指向危险截面。
4. pp5–6明确忽略预紧力等条件，再按伸臂/缩臂及仰角区分公式适用情形，最后写可编程的递推式。
