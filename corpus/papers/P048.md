# P048 — A method to predict the torsional resistance of suction caisson with anti-rotation fins in clay

年份：2021。文献类型：Marine Structures 75, 102866；2020 online/2021 volume。

文字阅读：PDF 1–22 页；实际渲染核对页：5, 6, 16, 19。页码均为 PDF 页序。

## 全文结构与论证链

实际扭转场景 → 抗旋翼概念与等效外径 → FE 和传统筒解析验证 → 翼数增加的局部/整体破坏转换 → 安装、脱开/粗糙度、翼长三个关键条件 → 单翼增益/多翼累加/可达上限的半解析方法 → 工程算例同时检查承载、安装与材料效率 → 适用边界。

## 可复用写作技法

1. PDF 2–3 页用三种真实非共面受力场景解释“为什么扭矩值得独立研究”，概念图紧接力学瓶颈而非先宣称创新。
2. PDF 7–8 页同一组数据既用容量系数也用各自峰值归一化，前者比较容量，后者比较动员速度；明确两种图回答不同问题。
3. PDF 9–13 页将不利条件单列为 Critical consideration，分别展示重塑、脱开和短翼的机制变化；不是把理想接触结果直接外推。
4. PDF 13–18 页把工程公式拆成单翼贡献、随翼数的递减增益、整体破坏上限，逐项给物理解释和拟合图；便于解释模型为何饱和。
5. PDF 18–20 页算例从需求出发反求翼宽/翼数，再检查所需与可用吸力和单位重量效率，形成设计决策闭环；结尾明确未考虑组合方向荷载。

## 图形风格（实际视觉）

- Fig. 4，PDF 5：黑色 FE 曲线，红色解析水平虚线，箭头直接标注公式/界面条件；上下分别两土类，开放轴、白底。
- Fig. 5，PDF 6：2×2 面板，行土类，列为容量系数/峰值归一化；无翼基准红色，其余黑灰连续族曲线，用箭头标出 N 递增而不是冗长图例。递增箭头只适用于有序且单调的族。
- Fig. 12，PDF 16：黑空心圆/三角是两土类数值点，红线为公式，图内标公式编号，统一对照编码。
- Fig. 15，PDF 19：四面板工程算例，土强度剖面、所需翼数读图、安装吸力、容量/重量效率；阈值线与交点投影线把曲线转为具体设计选择。源页横置，实际阅读时需旋转。
