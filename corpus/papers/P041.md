# P041 — Softening-based interface model and nonlinear load-settlement response analysis of piles in saturated and unsaturated multi-layered soils

年份：2024。文献类型：Computers and Geotechnics 171, 106331 期刊论文。

文字阅读：PDF 1–36 页；实际渲染核对页：6, 7, 16, 18, 22, 23, 31, 32。页码均为 PDF 页序。

## 全文结构与论证链

经典双曲线不能表征软化的缺口 → 黏着/摩擦机制与 DSC 扰动函数 → 三参数及特征点边界条件 → 七组界面试验比较 → 桩侧/端分量、饱和/非饱和有效应力与吸力 → 端阻修正数据集 → 弹性缩短和逐段迭代算法 → 参数来源讨论 → 五个现场案例 → 附录52组静载数据及 SPT 关联汇编。

## 可复用写作技法

1. PDF 2–6 页把新增模型从物理分量、扰动量、曲线形态、特征点边界四层推出，再比较硬化与软化两类试验；不同类型数据各自检验相应能力。
2. PDF 6 页 Table 1 标出用于确定参数的基线工况；PDF 21–24 页分别呈直接参数预测、经验修正预测、反分析拟合，区分证据层级，不能只报最小误差。
3. PDF 17–19 页先给力平衡和弹性缩短，再把求解写成分段迭代步骤与流程图，复杂推导最终落成可执行入口。
4. PDF 24 页同场1.5 m桩反演参数用于2 m桩预测，这一转移对照比同一曲线回拟合更有检验价值；叙述应保留参数共享范围。
5. PDF 20–29 页每案例复用“地层/桩几何→侧阻→端阻→总响应”的顺序，同时交代缺失 SWCC 借用相似土等证据限度。
6. PDF 28–29 页区分 O-cell 和静载曲线作为比较依据的不同角色，明确弹性缩短处理会影响可比性。
