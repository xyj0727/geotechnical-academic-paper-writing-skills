# P056 — A closed-form solution for the failure interaction diagrams of pile groups subjected to inclined eccentric load

年份：2022。文献类型：Acta Geotechnica 期刊论文。

文字阅读：PDF 1–14 页；实际渲染核对页：5, 9, 10, 12。页码均为 PDF 页序。

## 全文结构与论证链

广义荷载手算方法缺口 → 轴力/力矩已知解与假设 → 水平容量（先轴力无关，再引入截面 N–M 依赖） → 线性近似包络 → 数值分配程序逐步验证与算例 → 大轴力例外 → 结构破坏/岩土破坏与设计分项系数的区别 → 条件化结论。

## 可复用写作技法

1. PDF 3–6 页按复杂度递进：先列三条假设，然后在最简单包络上逐步加入轴力依赖；每次新增复杂性都对应图形变化。
2. PDF 7–10 页明确顶点解可由已知荷载分配得到，而顶点间直线只是近似，再写七步数值程序验证；把“推导”“假设”“检验”身份分开。
3. PDF 8–9 页给一个逐步数值算例，每步写中间荷载分配，不只报最终结果，可直接帮助读者复现算法。
4. PDF 10–13 页主动展示大轴压下近似偏差变大，并区分破坏条件与采用分项系数的设计条件；结尾明说结构优先控制只是启示，不是普遍免验规则。

## 图形风格（实际视觉）

- Figs. 2–3，PDF 5：相互投影的 Q–M、Q–H、H–M 坐标图；同一顶点跨图同色，虚投影线连通，顶点对应桩受压/受拉小图。有效的解析推导图，不是普通 x–y 折线。
- Fig. 9，PDF 9：三维多面体包络及有色切平面，旁放二维截面；颜色识别对应截面而非数值大小。透视遮挡以虚线表示。
- Figs. 10–11，PDF 10：实线数值解、虚线线性近似，顶点保持色码；近似偏保守一眼可见。
- Fig. 14，PDF 12：3×3 参数小多图，行土类、列直径；空心/实心圆表示轴压比，线型表示两个不同响应比；y=1 水平线标两类破坏控制转换。双纵轴虽然量纲都无量纲，也需明确变量，优先迁移为分面。

## 迁移和限制

可迁移：递进假设、投影对应色码、顶点/近似区分、算法中间量、反例限定。不可迁移：将结构控制判断变成取消岩土验算的规则；数值解仍受独立弹塑性桩/忽略桩间相互作用等假设限制。
