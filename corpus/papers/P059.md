# P059 — Pile and Pile Group Capacity: Some Findings from Centrifuge Tests

年份：2013。文献类型：作者接收稿；International Journal of Geo-Engineering 5(2)。

文字阅读：PDF 1–12 页；实际渲染核对页：8, 9, 10, 11。页码均为 PDF 页序。

## 全文结构与论证链

仓储封面 → 两个实际工程问题引出两项研究 → 共用离心试验制样条件 → 微型周边群桩装置/加载 → 带肋单桩钻孔、成桩、加载、几何与试验 → 分别报告两组结果与重复性 → 破坏定义和解析方法 → 综合结论。两个研究共享设施但问题与比较指标分开。

## 可复用写作技法

1. PDF 2–3 页从城市更新受限施工空间和桩身改形两个具体约束提出研究问题，背景服务于设计变量，而非泛泛强调重要性。
2. PDF 3–8 页把可重复性重点放在安装垂直度、定位、载荷传递、同样土样里的对照桩；方法细节的取舍直接对应可能的误差来源。
3. PDF 9–10 页主动交代异常曲线来自加载装置，并报告重复试验容量相近但破坏模式不同；不因结果不整齐而隐藏数据。
4. PDF 10–11 页先给平直桩重复性基线，再展示“带肋/同次平桩”的归一化提高率，消除批间土样差异；多种破坏判据都使用，不只挑有利判据。

## 曲线风格（实际视觉）

- Fig. 12，PDF 8 与 Fig. 13，PDF 9：灰度线型区分群桩，横轴模型沉降 mm，纵轴每桩平均力 N；配置 Fig. 11 与曲线邻近，有助解码简写。
- Fig. 15，PDF 10：两条验证荷载曲线及局部“5% Error”标注，将重复性作为可视证据。该误差不是全篇每一点自动成立的置信带。
- Fig. 16，PDF 11：相对于同次平直桩的归一化曲线；y=1 为 Plain Pile 直接标注，图内多线灰度，图例底部；小位移处比值波动明显，不能裁掉以制造稳定增益。

## 表格风格（实际视觉）

- Table 1，PDF 9：工况、间距、效率、破坏模式四列；横线及竖向列分隔均存在，不能统称三线表；效率两位小数，类别文字与指标并列。
- Table 2，PDF 11：横贯版宽的比较表；直径 mm、肋型、间距、增益百分数。只有水平分隔线，没有逐列竖线；增益带 + 号整数百分比，显示对照基准在表头中。

## 迁移与限制

可迁移：两个问题并列叙事、同批对照、重复性和异常说明、容量指标和机制类型联列表、直接标注归一化基线。不能迁移：模型比尺或所用破坏位移为通用规范；接收稿含占位符和文字笔误，不宜当正式版式或准确措辞模板。P058 为同类群桩研究的数值论文，和本篇实验汇总相关但不是同文。
