# P051 — Lateral Resistance of Finned-Piles in c–φ Soils: Experimental Investigations and Numerical Studies

年份：2023。文献类型：Indian Geotechnical Journal 53(5) 期刊论文。

文字阅读：PDF 1–18 页；实际渲染核对页：3, 6, 10, 17。页码均为 PDF 页序。

## 全文结构与论证链

陆上 c–φ 土适用缺口 → 土与钢参数、长柔桩判别、模型试验 → 三维 FE 和网格敏感性 → 六个参数系列（有无翼/偏心、位置、长、宽、方向、与承台连接） → 等承载条件材料比较 → 小尺度/大尺度数值对照 → 结论。

## 可复用写作技法

1. PDF 1–2 页将缺口同时约束到土类型和陆上尺寸/用途，避免把海上大直径翼桩结论直接替代陆上研究。
2. PDF 4–6 页先给位移控制的容量定义和翼效率分母，再用“系列—固定变量—变化变量”表组织六组研究；适合多参数 FE 稿件。
3. PDF 7–13 页对每个参数采用响应曲线→效率→沿深度弯矩→施工/材料约束，优化理由包含收益递减与可施工性；不是仅取最大承载工况。
4. PDF 12–17 页分“等承载改变直径”和“等承载改变长度”两种经济比较；把缩尺模拟单列，避免藏在方法一句话内。

## 表格风格（实际视觉）

- Tables 1–2，PDF 3：一张试验土性质清单、一张 FE 土/钢横向比较；单位随属性，非适用项用短横线，无竖线，顶/头/底三横线。
- Table 3，PDF 6：Series / Constant parameters / Variable parameters 三列，表下声明所有翼数和方向例外；适合工况设计的模板。
- Table 7，PDF 17：加载类型分组；列组 small-scale 下分 Experimental / ABAQUS，large-scale 下为 ABAQUS；没有试验结果留短横线，明确验证证据覆盖不齐。效率多为三位小数，不应与不适用项混为零。

## 迁移和限制

可迁移：分系列控制变量表、响应/效率/弯矩链、等性能比较、跨尺度证据表。不可迁移：“最优”尺寸、0.1D 容量判据、材料节省百分比作为普遍结论；全尺度数值放大不是独立足尺现场验证。原文单桩结果推测群桩优越性和最小间距，不能当群桩试验证据。
