# 模式矩阵、包络验证与分组表头

本页区分实际页面观察与模板设计选择。观察依据见 [P083](papers/P083.md)、[P085](papers/P085.md)、[P086](papers/P086.md)。字体磅值、线宽和精确颜色未从论文测量；模板值是可调实现。

## 模式矩阵与系列编码

P083 的 Figs.17–20（PDF pp10–13）以相同的四类运动模式构成 2×2 面板，加载速率的颜色/符号跨图保持一致。这种组织有利于把总体响应与局部量测逐项对照。

迁移规则：

- 面板固定一种条件或运动模式，系列固定另一变量；两种编码不要在后续图中互换。
- 显式给每个系列设置 `color`、`marker`、`linestyle`；不能依赖面板内的数组位置，因为部分系列缺测后默认颜色可能改变。
- 原文部分纵轴量程不同。新图若比较幅值，优先统一量程；若为了看形态而分开量程，清楚显示刻度和差异。
- 减少重复图例前，先保证跨面板编码一致且读者能辨识；不能把局部线型变化误说成相同系列。

示例 [mode-rate-matrix.json](../assets/examples/mode-rate-matrix.json) 使用 `kind: parametric`，是合成数据演示，不复现原论文曲线。

## 理论关系与离散样本分层

P086 的 Fig.8（PDF p7）用四个对齐剖面表达局部系数随深度的变化：横轴在上、深度向下、各面板量程一致；式(13)经验表达式计算曲线与空心 FEA 符号区分来源。Fig.10（PDF p9）采用 2×2 包络比较，几何条件固定在面板，土参数组固定为线型/符号。

迁移时先说明量纲、符号和归一化式，再选择坐标。`H/Href` 与 `M/Mref` 的参考量必须分别定义；原文的归一化分母不是通用默认值。相同数值刻度不代表相同物理量纲。

示例 [envelope-theory-check.json](../assets/examples/envelope-theory-check.json) 使用 `kind: interaction`。所有理论线与样本点都是合成示意，样本点不称真实 FEA 结果。旋转包络按路径顺序输入；闭合端点只有在输入明确给出时才保留。理论与样本同框，不按横坐标重新排序。

如果把包络中的代表点连到位移场或机制草图，保持点名、加载条件和阶段一致。P086 Fig.5（PDF p5）提供这种排列思路；定量场图另需变量、单位、色标范围和变形倍率，不能仅凭同色推断等值。

## 三线表中的两种比较层级

| 模板 | 原文观察 | 本库迁移方式 |
|---|---|---|
| `grouped-method-comparison` | P086 Table 1，PDF p8：行按几何条件；列按另一条件分组；每组内 FEA 与公式值相邻，无竖线 | 分组表头表达条件，子列表达参考/预测方法。符号和单位/归一化放表头或注释；需要误差列时另外定义分母，原表没有的误差列不能说成原文做法 |
| `paired-response` | P085 Tables 1–2，PDF p5：基线和改进方案为行，频率或测点为列，最后一行列相对变化 | 保留两行绝对值后再给变化量；说明正负方向和基线。不同单位不强行合并为一个共同单位 |

表头的分组线只跨所属列。HTML 预览中的可选 `column_groups` 实现一级条件分组，不提供任意合并单元格；复杂多层表头可按当前目标版宽拆表，或在后续 OfficeCLI 任务中制作。此处空表的“待填/未提供/未计算”不代表 0。

P083 Table 2（PDF p2）的工况分组可用于扩充已有 `case-matrix`：分开几何、加载位置/方向、速率与试验目的。若一行写多个水平，应说明这是水平列表还是实际组合；不要默认它们构成全因子试验。

## 跨图和图文一致性

交付前在目标版宽核对：轴分量与图题、物理量与单位、面板字母唯一、图例来源与线点角色、正负方向与归一化分母。P085 Fig.4（PDF p4）的分量标签和 P086 的交叉引用有核验线索，见证据卡。来源中的小字软件截图、缺少定量色标或过多有效位，属于观察记录，不应设为默认样式。
