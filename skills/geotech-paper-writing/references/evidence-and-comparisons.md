# 比较基准与证据边界

| 指标 | 必须交代 | 易错点 |
|---|---|---|
| 某位移对应抗力 | 测点、方向、绝对值或D归一化、插值方法 | 终点抗力自动改名极限抗力 |
| 增益比 r=A/B | 分子分母、同一评价点、B是否变化 | 达到r倍写成提高r倍 |
| 增幅 g=(A−B)/B | 基线、零/负分母处理、百分数 | 百分点与百分比混用 |
| 循环刚度 | 切线/割线/卸载/再加载、取点区间 | 用抗力比命名刚度 |
| YN/Y1 | Y1的测点、循环、工况 | 比值排名被当成绝对变形排名 |
| 贡献率 | 合力/力矩、积分面、方向、参考点、分母 | 用峰值或云图颜色代替贡献 |
| 极限/失效 | 判据来源、达到哪条、提前停止原因 | 服务性阈值当结构破坏或认证 |

## 三种公平比较

- 同外荷载：比较位移、转角及内力分布，给加载位置/方向。
- 同变形或使用限值：比较可承受荷载；较大内力可能源自施加载荷不同。
- 同性能需求：比较尺寸、用材或成本；质量节约不等于全寿命成本节约。

P015 pp11–16同时使用这些视角。砂与黏土采用不同归一化式时，轴上数值不能直接解释为绝对能力比。

## 验证段

试验身份/尺度/条件/比较量 → 一致与偏差区间 → 已定义误差量 → 可能原因 → 适用范围。P015 pp5–6指出小位移偏软、大位移偏硬，比“吻合良好”具体。不要生成未计算的误差百分比或R²。图片数字化数据标明来源和误差；标定集与验证集分开，参见P075 Tables4–5。

## 机制表述层级

观察（图和量测直接显示）→ 推断（与哪种机制相容）→ 定量闭合（积分与平衡）→ 外推（新条件独立依据）。能说明哪一层就写到哪一层。拟合、网格检查和现场验证不互相代替。
